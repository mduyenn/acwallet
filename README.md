# AC WALLET

A mobile-first Web3 payment wallet on Arc Testnet.

## Features

- **Auth**: Email OTP + magic link, injected wallet connection, and a Demo sandbox mode
- **Home**: real-time USDC balance sync from Arc RPC and ArcScan explorer
- **Transfer / Receive / Scan QR**: on-chain ERC-20 USDC transfers with wallet signing
- **Bills**: on-chain payments to deployed `BillReceiver` contracts on Arc Testnet
- **Split Bill, Budget Planner, Payment Reminders**
- **AC Pilot ✨**: AI financial copilot with on-chain wallet context
- **Earn 🌱**: curated yield opportunities with on-chain deposits to deployed vault contracts
- **Transaction History**: merged and deduplicated activity from RPC and explorer
